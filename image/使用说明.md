# ModifyArt - AI 写作助手 使用说明

## 启动

1. VS Code 打开 `ModifyArt` 文件夹 → F5
2. 新窗口中打开要编辑的 .txt 文件
3. 选中文本 → 右键 → `ModifyArt: 打开写作助手`
4. 选择操作 → 点「执行」

---

## 操作一览

| 操作 | 做什么 |
|------|--------|
| **润色改写** | 优化文笔、修语法、口语化 |
| **去除水句** | 删套话废话 |
| **智能分段** | 每行≤80字、对话独立成段 |
| **情节去重分析** | AI 扫描重复桥段、套路、模式化写法 | 重复模式诊断 |
| **逻辑一致性校验** | AI 查时间线矛盾、位置矛盾、因果断裂、认知矛盾 | 逻辑漏洞诊断 |
| **逐章改写** | 去水句→润色→分段，自动注入上下文 |

---

## L2 工作流

### 阶段一：情节去重分析

选中一章 → 选「情节去重分析」→ 点执行。

AI 输出分析报告（右侧查看），问题**自动提取**到下方面板。审核后可编辑、删除，确认后点「保存上下文」。

> 没有「应用到编辑器」——分析报告不会写入正文。

### 阶段二：逐章改写

选中一章 → 选「逐章改写」→ 点执行。

AI 带着上下文（人物档案 + 事件 + 当前章节问题）改写。不满意？在附加指令框输入具体意见 → 点「根据反馈修正」。

### 上下文 JSON 结构

每本书自动维护 `context/{书名}.json`，以**人物为单元**组织：

```json
{
  "人物": {
    "苏曼尼": {
      "性别": "女",
      "年龄": "26",
      "身份": "苏家二小姐",
      "状态": "存活",
      "性格": "因嫉妒而生恨，逐渐走向犯罪",
      "近期变动": "第92章盗取设计稿失败"
    }
  },
  "事件": {
    "第5章": "苏曼尼泼咖啡挑衅",
    "第92章": "苏曼尼潜入办公室盗取设计稿"
  },
  "设定": {
    "世界观": "现代都市商业竞争",
    "人物关系": "苏晚与苏曼尼同父异母，因继承权生矛盾"
  },
  "章节问题": {
    "第92章": ["盗取场景逻辑不通"],
    "全局": ["心理描写套路化"]
  },
  "改动记录": {
    "2026-05-31": "第92章：让苏曼妮崩溃更具层次感"
  }
}
```

**注入规则：**
- 人物档案 → 始终注入（AI 知道谁活着、谁死了、性格走向）
- 事件 → 始终注入
- 章节问题 → **只注入当前章节 + 全局问题**（不会把第86章的问题注入到第92章）
- 改动记录 → 最近5条

## 自定义 Prompt

模板在 `backend/prompts/`，修改即时生效：

| 文件 | 对应操作 |
|------|---------|
| `polish.txt` | 润色改写 |
| `remove_filler.txt` | 去除水句 |
| `format.txt` | 智能分段 |
| `dedup_plot.txt` | 情节去重分析 |
| `logic_check.txt` | 逻辑一致性校验 |
| `refine.txt` | 反馈修正 |

---

## 注意事项

- API 走 DeepSeek 官方接口，文本不离开本机
- 上下文自动注入每次 AI 调用，结果栏显示注入摘要
- 人物状态设为"已死亡"后，AI 不会在后续章节写该人物出场
