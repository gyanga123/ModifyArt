# 修改任务：第14章

## 章节原文

第14章：疯王发愿，吃尽长安包子！

李恪在暖阁里打了三个喷嚏时，阿福正拎着半湿的棉鞋往厨房跑。

"殿下！西市王记包子铺说今早只蒸了三百笼！"阿福推开门时，脑门还挂着白霜，"东市张娘子说她男人天没亮就去买面粉了，要晌午才能出笼——"

"全买。"李恪裹着李愔送来的狐皮斗篷，指尖正戳着案上冷掉的猪肉大葱包，"不管现蒸的还是隔夜的，连蒸笼带案板都给我搬回来。"他吸了吸鼻子，天机眼在眉心若隐若现，能看见长安城东南西北四个方向飘着的热气团，"跟百姓说，疯王请大家吃包子，管饱。"

阿福张了张嘴，到底没问"为何突然要请全城吃包子"。

自打昨夜殿下从护城河爬上来，他就知道这位三皇子的疯病又重了——可疯得越离谱，底下人越得把荒唐事办得周全。

他搓了搓冻红的手，转身往外跑，刚跨出门槛又被叫住。

"阿福。"李恪咬了口包子，汤汁溅在斗篷上，"挑二十个壮实小子，把包子摊支在东宫正门前。"他眯起眼，天机眼映出东宫朱漆门楼上缠绕的灰线，"要让太子殿下从早朝回来，一抬眼就能看见。"

阿福打了个激灵。

他跟着李恪三年，最明白这副疯癫模样下藏着的算计——上回殿下说要"学母鸡下蛋"，结果在太极宫后苑挖出了私藏的军械；再上回说"要给月亮编花环"，转头就把意图行刺的杀手堵在了望春楼。

所以当辰时三刻，东宫门前支起十张油布棚，棚下堆成小山的包子腾着热气时，长安百姓的惊呼声比晨钟还响。

"疯王这是要撑死自己？"卖糖葫芦的老王头踮脚往棚子里看，"昨儿还跳护城河，今儿就撒钱买包子——"

"您可别说。"旁边卖胭脂的小娘子拽了拽他袖子，"我表姐在崇仁坊当厨娘，说三皇子跳河前，国师袁道玄刚给四皇子算过命，说什么'龙脉骨现世，天命易主'。"她压低声音，"这会子疯王抢着吃包子，莫不是要抢那龙脉？"

人群里突然炸开一声锣响。

老张头晃着醒木从街角挤进来，灰布长衫沾着星点墨迹——他是西市最会说书的，专爱把宫闱秘事编成话本。

"列位看官！"老张头拍响醒木，"且听我老张头说段《疯王夺龙记》——"他故意拖长音调，"昨儿夜里，龙王爷托梦给疯王，说'要成真龙，须吃万笼包'！"他指了指油布棚，"您瞧这包子山，正是疯王在积龙气呢！"

哄笑声里，李愔的青缎小靴最先踏碎了热闹。

他跑得太快，腰间玉佩撞在门框上叮当作响，发冠歪在一边，额角还沾着厨房的面粉："哥哥！"

李恪正蹲在棚子底下啃包子，腮帮鼓得像仓鼠。

见弟弟跑过来，他故意把油乎乎的手往李愔衣襟上蹭："阿愔来得正好，这羊肉馅的没姜味，你尝尝是不是张娘子偷懒了。"

"哥哥！"李愔抓住他手腕，指尖凉得像冰，"阿福说你要买下全城包子，还在东宫门前摆摊——"他眼眶泛红，"你从前最厌这些虚浮事，如今怎么......"

"怎么？"李恪把最后半拉包子塞进嘴里，含糊不清道，"我梦见自己成了龙啊。"他突然拽住李愔的手按在自己心口，"你听，这儿烧得慌。龙王爷说，吃够一万个包子就能飞上天，到时候就能......"他顿了顿，咧嘴笑出虎牙，"就能给阿愔摘月亮。"

李愔望着他沾着油星的嘴角，突然想起昨夜在假山后捡到的半片龟甲。

那龟甲上的裂纹像极了袁道玄给皇子们算卦时用的"天谴纹"，可哥哥偏说那是自己跳河时撞碎的鹅卵石。

他吸了吸鼻子，伸手抹掉李恪脸上的面粉："那...那我帮你数包子。"

"好啊。"李恪揉乱他的头发，余光瞥见街角那株老槐树上晃动的衣角——影七的墨绿披风，是太子的暗卫。

他咬着包子冲李愔挤眼，"阿愔去帮我记账，记清楚每个铺子卖了多少，什么馅的最受欢迎。"

李愔没多想，转身跑向账台。

他没看见，李恪望着他背影时，天机眼里的灰线突然缠成了乱麻——那是天道杀劫在翻涌。

影七贴着老槐树往下滑了半寸。

他盯着油布棚里的李恪：那疯子从辰时到巳时，只吃了猪肉大葱馅的包子，每吃三个就抬头看一眼日晷，手里还攥着个小本，时不时在上面画两笔。

"奇怪。"影七摸了摸腰间的淬毒短刃，"若真是疯了，怎会记得每种馅的销量？"他注意到李恪的小本上画满了圈圈点点，其中崇仁坊、平康坊的标记尤其密集——那两处正是袁道玄常去的道观所在。

日头偏西时，影七的靴底已经沾了三层薄霜。

他最后看了眼油布棚，转身往东宫跑。

袖中密报上的字迹还未干："三皇子购全城包子，记录各坊销量，重点标注崇仁、平康。"

李恪是在戌时三刻摸到那叠数据的。

阿福举着烛台，照着书房墙上的长安地图——地图上密密麻麻贴着小纸条，每个纸条对应一个包子铺的位置，红笔圈出的是人流最密的区域。

"殿下，这是各坊的包子销量。"阿福递上账本，"平康坊的韭菜馅卖得最快，崇仁坊的牛肉馅最受欢迎——"

"不是销量。"李恪指尖划过地图上的红点，"是人心。"他的天机眼在暗夜里泛着金光，"百姓爱往哪挤，哪里就藏着最多的嘴。嘴多了，消息传得快，秘密也藏不住。"他突然敲了敲崇仁坊的标记，"袁道玄的'青元观'就在这儿。"

阿福打了个寒颤："您是说......"

"有人在借包子铺传消息。"李恪扯下崇仁坊的纸条，"昨天张娘子说，有个穿灰布衫的道士连着三天来买素馅包，每次都要把蒸笼最底下的三个拿走——"他突然停住，门外传来细碎的脚步声。

"三皇子！"卖菜的王婆婆颤巍巍掀开门帘，手里举着个油纸包，"老身卖完菜路过西市，见最后一个韭菜包没人要，想着您最爱这口......"她压低声音，"昨儿在后巷倒菜渣，见三个道士往老槐树底下埋东西，嘴里还念叨什么'聚气阵'......"

李恪的指尖在案上叩出急响。

他接过包子时，天机眼突然灼痛——那是危险临近的预警。

"阿福。"他撕开油纸包，里面躺着个韭菜馅包子，底部沾着半块朱砂，"带二十个暗卫去崇仁坊老槐树，挖地三尺。"他咬了口包子，味道不对，是掺了艾草的苦香——这是袁道玄常用的符咒材料。

系统提示音在耳边响起时，李恪正盯着地图上的崇仁坊标记。

【叮——宿主已收集长安各坊百姓聚集密度、情绪波动数据，可用于推演敌方布局。】

李恪舔了舔嘴角的艾草渣，突然笑出声。

他吹灭烛火，月光透过窗纸落在地图上，将崇仁坊的标记照得发亮。

"老张头说我要成真龙。"他对着夜色低语，"那袁国师，可要当心龙的爪子了。"

子时三刻，李恪换了身青布短打。

他望着案头最后一个韭菜包，将它塞进怀里，推开了书房后窗。

寒风卷着雪粒子灌进来，吹得地图上的纸条哗哗作响。

其中一张写着"崇仁坊·老槐树"的纸条被吹落在地，恰好盖住了"青元观"三个字。

窗外，更夫的梆子声远远传来："天干物燥——小心火烛——"

李恪摸了摸怀里的包子，嘴角扬起抹笑。

他翻身跃上屋檐时，月光正照在他眉心那点金芒上，像颗藏在云里的星。

## ⚠️ 注意事项

1. **李愔称呼**：李愔对李恪说话应称"哥"不是"哥哥"
2. **龙脉骨知情权限**：百姓传言中不能出现"骨头/龙骨/龙脉骨"（修道之人除外）
3. **删"下章预告"**：章末"（下章预告：...）"是预告格式，非正文，须删除
4. **章尾升华**：最后一段"月光正照在他眉心...星"可精简
5. **删"仿佛/似乎/好像"**、简化"嘴角扬起抹笑"
