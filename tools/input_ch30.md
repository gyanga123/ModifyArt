# 修改任务：第30章

## 章节原文

第30章：疯王斗国师，太极殿对峙！

五日后子时，太极殿飞檐上的星子坠成银霜。

李恪仰头望着檐角铜铃被夜风吹得轻晃，喉结动了动——这是他第三次摸进皇宫，前两次偷过尚食局的糖蒸酥酪，顺过御书房的《九章算术》，可这回裤脚沾的不是蜜渍梅汁，而是浸透鞋底的冷汗。

"殿下。"铁九的声音从左侧廊柱后飘来，他裹着夜行衣，脸上涂着青黑的草汁，手里攥着半块被磨尖的青砖，"西北角的巡卫换班了，阿福已经引开最后一拨守夜的小太监。"

李恪摸了摸腰间的玉坠，母亲杨妃临终前说这是隋朝皇室秘传的"避厄珏"，此刻触手生温，倒像在替他数心跳。

他从袖中抖出折叠刀，刀身映着月光，"骗你是小狗"六个字泛着冷光——这是他穿越前在夜市淘的，原以为是哄小孩的玩物，此刻倒成了压箱底的底气。

"走。"他低喝一声，猫着腰钻进影里。

三人贴着汉白玉栏杆往殿后挪，李恪的左眼突然泛起热意，天机眼自动睁开，视线穿透青石板，在地下三尺处捕捉到暗纹流转的阵图——那是袁道玄设的"锁龙局"，阵心正对着李愔的生辰八字。

"在这儿。"他蹲下身，用刀尖敲了敲第三块方砖，"铁九，拆机关。"

铁九从怀里摸出半套铜制工具，指甲盖大小的撬棍刚插进砖缝，地底便传来嗡鸣。

李恪的太阳穴突突直跳，系统提示音在脑海炸开："检测到'龙脉共鸣'仪式启动，剩余时间：三刻钟！"

"快！"他拽着铁九的后领往下一按，青石板突然翻起，露出黑黢黢的地道。

阿福举着火折子探进去照了照，火苗忽明忽暗，映出地道尽头两扇刻满符咒的石门。

"袁老道的手笔。"李恪舔了舔嘴唇，喉咙发紧。

他想起李愔今日在御花园扑蝶时，袖口沾了黄蝶粉，偏要凑过来给他看："阿兄你瞧，这蝴蝶的翅膀像不像龙鳞？"那时他笑着揉乱弟弟的发，心里却像压了块烧红的炭——若再晚一步，这双沾着蝶粉的手，就要被剥去龙鳞骨当祭品了。

石门后传来诵经的咒语声，混着某种兽类的低嚎。

李恪的天机眼突然刺痛，他看见石门内的景象：袁道玄盘坐在血池中央，周身缠着九条金绳，每条绳上都钉着李唐宗室的生辰八字；李愔的"龙脉骨"悬浮在他头顶，泛着幽蓝的光，正缓缓融进他眉心的朱砂痣里。

"狗东西！"李恪抄起腰间的符纸（这是铁九用牛眼泪和朱砂画的，说是能破术法），反手掷向石门。

符纸触到门的瞬间炸开金光，咒语声猛地一滞，接着传来瓷器碎裂的脆响——袁道玄的法坛被震翻了。

石门"吱呀"一声开了。

袁道玄抬起头，道袍前襟沾着血，眼睛红得像淬了毒的蛇。

他望着李恪，忽然笑了："三皇子好手段，竟能破我的'锁龙局'。"他指尖掐了个诀，血池里的金绳突然活过来，"不过你以为仅凭这点小术法就能阻我？这天下的气运，该换个主了！"

李恪的左眼看见金绳上缠着的黑气——那是天道杀劫的余孽。

他退了半步，撞在铁九身上。

铁九立刻从怀里摸出个铜球，往地上一抛，地道里顿时腾起白雾。

"幻镜阵启动！"他压低声音喊，"殿下，按之前说的，引他进错层！"

袁道玄的金绳缠上李恪的脚踝，疼得他倒抽冷气。

他故意踉跄着往前扑，大喊："你以为你是天道代理人？你不过是它养的一条狗！连李愔的龙脉骨都要偷，你配称国师？"

袁道玄的脸瞬间扭曲。

他最恨别人提"偷"字——当年他跪在终南山巅求了七七四十九天，才从天道那里讨来"代理人"的名号，可此刻被个毛头小子当众戳穿，哪里忍得住？

他挥袖震碎金绳，追着李恪冲进白雾里。

"成了！"李恪在心里喊。

他的天机眼穿透白雾，看见袁道玄正站在幻镜的第三层，而真正的阵心在第五层。

他拽着阿福往左边跑，铁九在右边敲了敲铜球，白雾里传来袁道玄的怒吼："你耍我！"

"影七！"李恪突然拔高声音，"该你了！"

一道黑影从地道顶端的通风口窜下来，快得像把淬毒的刀。

袁道玄刚要转身，脖颈已被影七扣住。

影七的指尖抵着他后颈的大椎穴，冷笑："袁国师，陛下让我带句话——他早看出你借'龙脉骨'引天道的心思，夜枭的供词，三皇子可是原封不动呈给了圣驾。"

袁道玄的瞳孔剧烈收缩。

他想起五日前太子李承乾来齐王府时，李恪故意放风说"练功走火"，原来那根本不是障眼法，是给皇帝递消息的暗号。
