# 修改任务：第21章

## 章节原文

第21章：疯王夜访包子铺，真相初现！

长安的夜像块浸了墨的布，李恪裹着青布短打缩在巷口，后颈那点灼痛随着接近崇仁坊愈发清晰。

他往脸上又抹了把灶灰，指尖触到粗糙的颗粒，混着市井烟火气钻进鼻腔——这是他从东宫灶房顺来的，专用来混过巡城卫的眼。

包子铺的灯笼在巷尾晃着，"张记"两个字被风吹得忽明忽暗。

他记得老张头说书时挤眉弄眼的模样："那铺子看着卖素包，可每到子时三刻，后院总飘着股怪味儿，像烧纸又像...血锈。"

李恪踩着青石板往前走，鞋跟磕在砖缝里发出细碎的响。

铺子门半掩着，灶膛里的余火映得窗纸泛红，能听见蒸笼"咕嘟"冒气的声音。

他伸手推门，木门"吱呀"一声，惊得里头擦桌子的伙计抬头："客官打烊了——"

"留俩素包成不？"李恪掏出碎银往柜台一丢，故意弓着背缩脖子，活像个偷摸买宵夜的小帮工，"我家主子嘴刁，非得这口热乎的。"

伙计盯着银子眨了眨眼，转身掀开蒸笼时，李恪的目光已经扫过整间铺子。

木桌腿上有道新刻的符咒，被茶渍掩着；墙根的米缸摆得歪了三寸——这是阵眼偏移的痕迹。

他摸了摸袖中叠好的符纸，后颈突然一烫，天机眼在识海深处睁开。

眼前的景象瞬间扭曲。

青灰色的气线从地底钻出，缠着包子铺的房梁往上窜，在屋顶聚成团黑雾。

李恪喉结动了动——这不是普通的市井烟火气，是引魂聚煞阵特有的阴煞之气，他在袁道玄的道经里见过画像。

"客官，您的包子。"伙计端着竹篾盘过来，李恪接过时故意踉跄，竹盘"啪"地摔在地上。

素包滚到柜台底下，他弯腰去捡，指尖触到青砖缝里的血渍——还没干透，带着股铁锈味。

"对不住对不住！"他赔着笑直起身，袖中符纸已经捏成一团。

等伙计蹲下去收拾，他指尖快速结印，符纸"唰"地撒向空中。

青雾腾起的刹那，整间铺子的轮廓变了。

原本的木梁化作黑色锁链，青砖地面裂开蛛网般的纹路，每道缝里都爬出细如发丝的红绳，直往地下钻。

李恪倒吸口凉气——这阵法的核心竟在地下三尺，用活人血引着煞气，分明是要把天道杀劫往某个方向引。

"袁道玄，好狠的手。"他低骂一声，天机眼映出阵心刻着的生辰八字。

虽然被抹得模糊，但那熟悉的骨相特征让他心脏猛跳——是李愔的。

后颈的灼痛几乎要烧穿皮肉，李恪从怀里摸出枚青铜钉。

他蹲下身，钉尖对准阵眼，正要发力，门外传来"嗒嗒嗒"的脚步声——不急不缓，每一步都踩在青砖缝里，像量过尺寸。

李恪后背一紧——是影七，这脚步声他听了三年，绝不会认错。

"客官？"伙计端着新蒸的包子出来，见铺子里的黑雾愣住，"这、这什么味儿？"

李恪顺势踹翻长凳，抓起个包子塞进嘴里："好香！张记的素包天下第一！"他满嘴油星地往门口走，与影七擦肩时，把青铜钉悄悄塞进影七腰间，"大人也来俩？这家的韭菜馅，包您吃了还想吃。"

影七低头看了眼腰间的青铜钉，猛地转身时，李恪已经钻进夜色里，只留下句："明早我来收账——账本在铺子后院的槐树底下！"

影七握着青铜钉，指节泛白。

他认出这钉子上的纹路——是太子的东宫暗卫专用的镇魂钉。
