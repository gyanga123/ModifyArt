# 修改任务：第8章

## 章节原文

第8章：疯王早朝上演"鬼打墙"！

三日后，早朝。

太极殿内百官列阵，气氛凝重。

御史大夫杜淹身着紫袍，面如寒霜，手中紧握一卷奏折，目光在殿门口来回扫视。

他身后几人亦是神色不善，皆为他的心腹党羽，早已磨刀霍霍，准备一举将李恪逐出长安。

"陛下。"杜淹上前一步，拱手高声，"臣有本启奏！"

魏征站在文官队列中，眉头微皱，虽未与杜淹同流合污，但对李恪近来种种怪异行径也颇感疑虑。

这位皇子，前日还装疯卖傻于东宫不起，今日又不知要搞什么名堂。

李世民端坐龙椅之上，神情不动如山，只淡淡道："讲。"

杜淹朗声道："臣参劾吴王李恪，行为乖张、屡犯纲纪，且居心叵测、图谋不轨！其近日更私通不明之术，妖言惑众，恐生祸乱。恳请陛下将其贬离京城，以正纲常！"

此言一出，群臣哗然。

"竟有此事？"

"吴王素来顽劣，但不至于至此吧？"

"若真如此，确实该严惩！"

有人窃窃私语，有人冷眼旁观，也有人暗自欣喜。

魏征终于忍不住开口："杜大人所言可有证据？不可空口白牙便定亲王之罪。"

杜淹冷笑一声，展开奏折："证据自然有——诸位可听闻吴王昨夜召邪士入府，施咒祈福，意图不轨？更有百姓传言，其已修炼邪术，能役鬼神！"

"荒谬！"魏征怒斥，"子虚乌有之事岂能作数？"

就在这时，殿外传来一阵清脆的铜铃声响，叮铃作响，带着几分诡异的节奏。

众人纷纷侧目望去。

只见一人踏步而入，身穿一袭五彩斑斓的古怪长袍，头戴羽毛冠帽，腰间挂满铃铛，手里拎着一面铜铃，边走边摇，口中念念有词，似在吟诵某种咒语。

正是李恪！

他脸色苍白，眼神迷离，仿佛刚从梦中醒来一般，脚步虚浮，却每一步都踩得格外有力，仿佛踩在众人的心头。

"鬼来了……鬼来了……"他低声呢喃，声音沙哑而诡异。

群臣惊愕。

房遗爱瞪大眼睛，几乎不敢相信自己的耳朵："这……这是吴王？他疯了？"

杨妃在帘后窥见这一幕，心头一颤，眼中满是担忧。

李恪走到殿中，忽然停下脚步，抬头望向龙椅上的李世民，嘴角露出一抹神秘笑容。

"父皇……今晨我梦见一只黑猫跃上金銮，九尾盘旋，煞气冲天。"他说着，突然猛地一拍铜铃，金属碰撞之声回荡整个大殿！

刹那间，空气中似乎有一丝异样的波动，四周光线微微扭曲，紧接着，几道模糊不清的幻影赫然出现在空中！

那幻影身形飘忽，轮廓隐约可见人形，动作僵硬，仿佛幽冥之中的游魂，缓缓地在大殿中央漂浮旋转。

"啊！"有人低呼，连连后退。

杜淹更是脸色大变，连连倒退两步，指着李恪厉喝："你……你这是何等妖术！竟敢在朝堂之上施展邪法！"

"妖术？"李恪嘴角勾起，轻笑一声，"我不过是请几位'贵客'来瞧瞧真相罢了。"

他话音未落，那些幻影忽然开始动了起来，仿佛回忆般重现某些画面。

其中一道身影极像杜淹，正与一个看不清面容的人影在黑暗中密谈。

虽然细节模糊，但那轮廓、那姿态，已然足以令人心生怀疑。

李世民目光一沉，眼中精光一闪而过，随即不动声色地挥了挥手。

侍卫们悄然靠近，隐在暗处观察。

魏征皱眉盯着那幻影，心中疑惑更深。

"这不可能是幻术……"他低声自语。

而另一边，袁道玄站在武官一侧，眯着眼看着这一切，嘴角勾起一丝意味深长的笑容。

"有意思……这小子，竟能藏得如此之深。"

李恪却依旧一副癫狂模样，手持铜铃，在殿中跳起了奇怪的舞步，嘴里哼唱着不知名的调子，脚步凌乱却诡异地契合节拍。

他一边跳，一边大声喊道："驱邪啦！除魔啦！你们看不见吗？他们就在我们身边！"

群臣震惊之余，有的已忍不住笑出声来。

"这……这也太荒唐了吧？"

"吴王是不是疯了？"

"不对劲……这绝非寻常之术……"

只有少数几人察觉到不对，尤其是裴矩，他站在人群中，目光深沉，嘴唇微动，低声道："他在演戏……但也在布局。"

李恪的表演仍在继续，他猛然转身，面对李世民，双膝跪地，双手高举铜铃，语气悲怆："父皇！儿臣无才无德，但也知忠孝二字！如今妖孽作祟，儿臣愿以自身为祭，驱邪护国！"

他这一番话，说得慷慨激昂，却又透着一股说不清道不明的凄凉。

李世民沉默良久，终是开口，声音低沉而威严："够了。"

李恪立刻收声，跪伏于地，不再言语。

殿内一片寂静，只有风穿过窗棂的声音。

李恪低头垂眸，掩去眼中那一抹锐利。

幻影尚未完全消散，空中残留着那诡异的余韵，仿佛真有幽冥鬼魂在朝堂游荡。

杜淹脸色铁青，额角渗出冷汗。

他死死盯着那些模糊的画面——画面中的"自己"正与一个披着斗篷的人低声密谈，地点隐秘，语气焦躁，像是在谋划什么大事。

可……那是真的吗？

杜淹心中大骇，他确实曾与人私会，但绝非叛国之谋！

只是想借机扳倒李恪罢了！

可如今，这一切被当众"揭露"，哪怕真相未明，也已足够动摇圣心！

李世民缓缓站起，目光如炬，扫过杜淹，又落在李恪身上。

他不动声色地抬手，侍卫悄然上前一步，眼神锐利如鹰隼，随时准备行动。

"我不是疯子，是他们要害我啊！"李恪突然伏地痛哭，声音凄厉，情绪激动，"儿臣昨夜梦见妖魔缠身，醒来便觉不安，这才请来异士设法驱邪。谁知……谁知这朝堂之上，竟真藏了奸佞之人！"

他这一哭一喊，反倒将原本对他不利的局面逆转了几分。

有人开始窃窃私语。

"吴王虽顽劣，却素来聪慧，怎会无缘无故发疯？"

"那幻影若真是虚妄，杜大人何惧？"

"怕不是他暗中做了什么事，才被揭穿吧？"

魏征站在原地，眉头紧锁，虽不信邪术，但也察觉不对劲。

"陛下。"他上前一步，拱手道，"此事蹊跷，真假难辨，不如暂缓处置，彻查幻影来源，方显公允。"

房遗爱见状，立刻附和："对对对，先查清楚再说，不能冤枉好人啊！"

杜淹急了，连忙辩解："陛下，微臣忠心耿耿，岂敢勾结外人！此必是吴王故意制造幻象，污蔑臣下！"

"污蔑？"李恪忽然抬起头，嘴角一抹冷笑，"杜大人，你昨晚说的是'时机已到'、'只等今日早朝'，难道是在夸奖我吗？"

"你胡说！"杜淹怒吼，但声音已有些发颤。

李世民抬手止住争论，淡淡道："暂且不议。朕要亲自查证此事。退朝。"

话音落下，群臣纷纷行礼，三三两两地退去。

殿内气氛陡然松动，却又压抑得令人窒息。

待众人离去，李恪悄悄起身，眼角还挂着泪痕，却转瞬恢复清明。

他瞥了一眼角落里低眉顺目的小太监阿福，轻轻眨了眨眼。

"今晚，去给杜大人送点'惊喜'。"

阿福低头应了一声，转身迅速消失在宫墙阴影之中。

太极殿外，阳光明媚，春风拂面，而一场更大的风暴，正在酝酿……

远处，国师府方向乌云隐隐聚拢，似乎已有风雨欲来之势。

## 修改规则

### ✅ 必改：身份称呼不符
- 杜淹参劾时称"吴王李恪"→ 应称"三殿下"或"三皇子"（弹劾场合也不例外，参照V1规则第2条）
- 朝臣议论时"吴王"→ 可用"三殿下"或保留"吴王"（符合贵族语境）
- 房遗爱直呼"吴王"→ 私下可，但朝堂上应更正式

### ✅ 必改：龙脉骨设定
本章无直接提及，但注意：
- "私通不明之术，妖言惑众" 保持现状（与龙脉骨无关，正确）
- "能役鬼神" 保持现状（百姓传言，合理）

### ✅ 选改：水文压缩
- "仿佛""似乎""好像"等多余词 → 删除或改写
- "嘴角勾起一抹""嘴角露出一抹" → 简化为"笑了""冷笑"
- 杜淹内心独白"可……那是真的吗？""杜淹心中大骇"段较啰嗦 → 适当压缩
- 章尾"风暴正在酝酿""风雨欲来" → V1规则9要求删除章尾升华

### ✅ 必改：V1规则适用
1. 章节开头有辨识度 → "三日后，早朝" 没问题
2. "不是……而是……"句式 → 检查是否有，有则删
3. "嘴角勾起一抹" → 已标记
4. 章尾升华不删 → 但"风暴正在酝酿""风雨欲来"属于重复渲染，应精简
