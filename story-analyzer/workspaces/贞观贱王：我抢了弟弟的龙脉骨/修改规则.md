# 修改规则

> 适用：贞观贱王：我抢了弟弟的龙脉骨
> 原则：不改情节结构，最小改动量，不影响有声演播听感

---

## 一、改什么

### ✅ 必改：逻辑硬伤

听众能听出来的前后矛盾，一处改 1 行。

- 角色行为打脸（上集说不能，下集做了）
- 设定前后冲突（同一件东西作用不一样）
- 进度/数值倒挂（觉醒 100% 又变回 45%）

### ✅ 必改：身份称呼不符

人物对话/旁白中，称谓语与人物身份不符的，一律修正。

**尊称对照表：**

| 被称呼者 | 谁称呼 | 正确叫法 | 错误例子 |
|---------|--------|---------|---------|
| 皇帝（李世民） | 任何人 | "陛下""皇上""父皇" | 不能直呼"李世民" |
| 太子（李承乾） | 皇子/臣子 | "太子殿下""太子" | "李承乾"（除非蔑视） |
| 三皇子（李恪） | 太监/侍卫/宫女 | "三殿下""三皇子" | "李恪"（大不敬） |
| 四皇子（李愔） | 太监/侍卫/宫女 | "四殿下""四皇子" | "李愔""小王爷" |
| 魏征等重臣 | 太监/侍卫 | "魏大人""魏相" | "魏征"（当面直呼失礼） |
| 杨妃 | 太监/宫女 | "娘娘""杨娘娘" | "杨妃"（当面） |

**例外可直呼其名的情况：**
- 袁道玄（国师，地位超然，可直呼皇子名以示蔑视）
- 魏征弹劾时故意不称爵位（贬低效果）
- 内心独白/旁白叙事（自由）
- 同辈皇子之间互称名字或"三弟""四弟"

### ✅ 选改：水文压缩

一段话删了不影响听众理解主线剧情的，删。

- 删除与主线无关的动作描写（同一动作重复 3 遍的留 1 遍）
- 删除过长战斗中的过渡回合
- 删除内心独白中的重复纠结
- 删除"不是……而是……"等 AI 句式

### ✅ 必改：龙脉骨设定连锁修正

龙脉骨已从"物理骨头"改为"只有修道之人能感知的气运灵物"。
所有与之相关的对话、旁白、朝臣议论，必须统一改写。

**需要排查的场景类型：**

| 场景 | 错误表述 | 正确表述 |
|------|---------|---------|
| 朝臣议论 | "当众抢弟弟的骨头" | "当众对弟弟做了什么古怪事，像是拿了什么东西" |
| 魏征弹劾 | "夺取龙脉骨，大逆不道" | "行径诡异，恐施行妖术邪法" |
| 百姓传言 | "疯王夺龙骨" | "疯王对他弟弟下了什么手" |
| 李恪装疯 | "想吃糖才拿骨头" | "想吃糖才抢他东西" |
| 袁道玄告状 | "龙脉骨被李恪强行取出" | "龙脉骨气息被李恪窃走" |
| 杨妃质问 | "你为何要抢走愔儿的龙脉骨" | "你究竟对愔儿做了什么" |
| 系统提示 | "夺取李愔龙脉骨" | "截取李愔的龙脉骨气运" |

**核心逻辑：普通人看不见龙脉骨，只看到李恪扑向弟弟、拿了什么、装疯。只有袁道玄及修道之人知道真相。**

**重要：第13章后龙脉骨已被袁道玄窃走，李恪手里只剩玉牌（注入了一缕龙气）。此后所有章节中，李恪不能再有"龙脉骨在身"的描写——只能写玉牌、龙气、替劫阵。涉及雷劫/挡劫场景，驱动阵法的是玉牌中残留的龙气，不是龙脉骨本身。**

## 二、不改什么

### ❌ 不改：写作风格

- 章末结尾句式
- 战斗六步模板
- 招式命名习惯
- 节奏规律

### ❌ 不改：不影响听感的

- 时间线模糊
- 实力小幅波动
- 道具偶尔不出现

---

## 三、怎么改

### 修改手法

```
找到矛盾 → 定位原文 → 改一句话或一个词 → 连锁修正所有相关处
```

每处改动不超过 2 行。改完后通读，确认没有因修改产生新的断尾。

### 输出位置

```
workspaces/贞观贱王：我抢了弟弟的龙脉骨/output/改文_贞观贱王.txt
```

原文不动，改文单独追加保存。

### 验证方法

改完后通读一遍，问自己三个问题：

1. 这段改之后，后面的剧情还能成立吗？
2. 有没有因为改了称呼或设定导致某段对话不合情理？
3. 如果只听有声版，能听出这里被动过吗？

## 四、修改经验积累（持续更新）

每次修改中用户反馈的问题，积累在此，后续改文必须遵守。

### V1 2026-06-06

1. **章节开头/结尾不要重复** → 相邻章节不要用同样的开头句式（如连着两章"夜色如墨"）。每章开头要有辨识度
2. **魏征弹劾也不能直呼皇子名** → 应称"三殿下"或"三皇子"，弹劾场合也不例外
3. **普通人不知龙脉骨** → 李愔、房遗爱、朝臣、百姓等非修道之人，对话/旁白中不能提及"龙脉骨"被取走
4. **龙脉骨是气运灵物** → 只有袁道玄等修道之人能感知其气息，普通人看不见
5. **"不是……而是……"句式** → AI 特征明显，删除或改写
6. **"嘴角勾起一抹苦笑/冷笑"** → 改为简短的"苦笑""冷笑""诡异的笑了"，去掉"嘴角勾起一抹"
7. **景物描写精简** → "月光如水""夜色如墨"等四字套话，非必要不用
8. **重复场景必须合并** → 同一事件出现两个版本的，保留信息完整的，删重复的
9. **章尾升华不要** → "他不是为了权势，不是为了称帝"这类总结段落直接删
10. **多余比喻删** → "仿佛""好像""如同"非必要不用
11. **内心独白不堆叠** → 同一个意思反复说的，留一个最强的
12. **OpenSquilla改文标注要清理** → 【改N】、【改N理由】、修改说明表格、验证三问等，追加到正文前必须删干净
13. **破折号节制使用** → 同一段落内最多出现一次「——」。不要用"叙述句+——+补充说明"套路句式，该用句号或冒号的地方就用句号和冒号
14. **阿福（太监）称皇子标准** → 阿福对李恪称"殿下"，对李愔称"四殿下"，不得用"小王爷""小主子"等非标准称呼。太监/侍卫对皇子统一用"殿下"
15. **李愔对李恪称呼** → 叫"哥"不是"哥哥"。亲兄弟之间没那么客套，李愔对李恪喊"哥"即可，"哥哥"太文气
16. **李恪画符依赖链** → 李恪画符须同时满足两个条件：(1)系统奖励了对应的符箓技能 (2)用天机眼验证灵力波动。两者缺一不可，不能凭空画符

## 五、经验积累（从用户改稿中提炼，持续更新）

### E1 李愔不能探知龙脉骨
李愔只知道哥哥抢了自己的龙脉骨、行为古怪，但他**不会道法，不能感知"龙脉骨"在哪里**。他的台词里不能出现"龙脉骨""龙骨"等词。他问应该问"那是什么？"而不是"那是我的龙脉骨？"

### E2 袁道玄当面称呼
袁道玄虽然地位超然，但在有第三方（影七、侍卫等）在场时，称李恪应叫"三皇子"而非直呼"李恪"。直呼其名只适用于私下蔑视场合。

### E3 影七立场模糊
影七是皇上派给袁道玄协助的护卫，不是袁道玄的私兵。他的台词要体现这种立场摇摆——他吃皇粮，不是袁家的狗。

### E4 删回忆解释段
大段回忆性对话（"你记不记得上个月..."）直接删掉，让读者通过行动和反应理解人物关系。用短句、"哥！"李愔哭出声 这种情感爆发代替解释。

### E5 李愔声音描写
李愔的声音"发颤"比"带着哭腔""哽咽"等更简洁有力。全文统一用"发颤"。

### E6 冗余修饰删
"后颈的"、"原本褪色的"、"那排新翻的"等不必要的定语，能删就删。句子越干净越好。

### E7 法术要有可见效果
点了"幻象阵成了"不能就完了——要让读者看到幻象作用在谁身上、产生了什么变化、旁观者如何反应。否则就是废设定。

### E8 让对手自曝
与其让李恪装疯卖傻演半天，不如用幻象/阵法让对手当众出丑——清风子在幻象中自喊"妖气缠身！皇子要造反！"比李恪在地上打滚更有说服力，围观群众自然看出"原来这道爷才疯了"。

### E9 友人对话要自然
房遗爱这类朋友角色，对话可以带调侃、有私交感（"咱能不能别每次装疯就选那护城河跳"），不要端着。朋友间的对话越放松越真实。

### E10 删计划性脱身细节
竹筏、绳索、预埋的油布等"计划性逃脱"的提前布置描写，删掉。让逃脱看起来更像临场反应，更紧张真实。

### E11 比喻能删就删
"像在哄受了惊的幼兽""声音像片羽毛"等比喻性描写，能删就删。让动作自己说话，不要帮读者理解"这像什么"。

### E12 道具原理整段删
酒里下什么药、怎么下的、什么粉混什么粉——这种原理性说明整段砍掉。只写"酒坛早下了迷魂散"就够了。读者不需要知道配方，只需要知道"被下药了"。
