## 四、长期可探索（不限技术选型）

这些不决定架构走向，但你可以知道有这些可能性：

| 方向 | 技术选型示例 | 价值 |
|------|------------|------|
| **Web 看板** | 纯静态 HTML + GitHub Pages / 飞书多维表格 | 不打开 IDE 就能看进度 |
| **网盘同步** | rclone / 百度网盘 API 定时备份 `workspaces/` | 本地丢了也不怕 |
| **Git 版本管理** | 每个分析周期自动 commit | 追溯"什么时候改了哪里" |
| **多本书并行进度** | 飞书多维表格 / Notion 数据库 | 团队协作时能看全局 |
| **分析结果推送** | Webhook / 飞书机器人消息 | 分析跑完自动通知你 |

**我的建议：先不做。** 等你同时有 3 本书在管，自然知道哪个方向最痛。

## 五、切新书的完整操作流程（改造后）

```bash
# 1. 创建新书工作区
bash setup-book.sh "新书名" "d:/path/to/原文.txt"

# 2. 检查环境
bash story-analyzer/init_env.sh

# 3. 跑 Phase 1（从第1章开始）
python pipeline.py --book 新书名 --phase 1

# 4. 续跑（第二天）
python pipeline.py --book 新书名 --phase 1 --resume

# 5. Phase 2（概要够了就开跑）
python run_phase2.py --book 新书名 all
```

**切换回旧书：**

```bash
# 查看旧书状态（看状态快照）
cat story-analyzer/workspaces/逆世天途/状态快照.md

# 继续改稿
python pipeline.py --book 逆世天途 --phase 1 --resume
```
